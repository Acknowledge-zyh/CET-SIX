# 六级单词复习

一个帮助备考大学英语六级（CET-6）的单词复习网站。

- 目标用户：备考六级的学生
- 核心场景：利用碎片时间快速过单词、标记生词、按计划复习

## 状态

项目刚启动（2026-09-22），暂无代码。后续文档与代码将按任务清单逐步添加。

## 本地运行

1. 在项目文件夹打开终端，执行：`python -m http.server 8001`
2. 浏览器打开 http://localhost:8001

## 功能（v0）

- **新单词学习**：8 个六级高频样本词，点「学会了」记入浏览器本地存储
- **昨日单词复习**：昨天学过的词出现在这里，先回想再点开释义
- 学习记录保存在本机浏览器（键 `cet6_learned_v1`），换浏览器/换电脑不共享
